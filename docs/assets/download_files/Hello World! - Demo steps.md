
## GitHub Desktop step-by-step
create folder
make a txt file
add to github
write line
commit - detailed message
write another line
commit

show github repo on remote (before)
undo one of the commits in history tab

add collaborator - on the same repository
clone repo
Make branch
switch to branch
open folder -> file
make commit
push commit
go to website
everyone make a pull request from your branch to the collaborator's branch

## command line step-by-step

Other half clone the repo
git checkout `<branch name>` switch from main branch to your branch
make a new file and make a change to the original one (you can from the command line if you want, but not necessary)
git diff `<filename>`
git status
git add
git rm the new file
git commit
git log
make another 2 changes, commit after each one
make a 2 more changes
git status
git clean to remove changes
git status again
git checkout `<hash>`
git reset `hash`
